# TimerApp

This project is developed using STM32CubeIDE,runs on the STM32 NUCLEO-U575ZI-Q
board. The onboard LED2 (PB7) blinks every 1000 ms. Text message is printed via 
UART1.  

## Features

The executable, object are in **Binaries** and  **debug**.


## Prerequisites

**STM32CubeIDE** ≥ 1.18.1  
**STM32CubeMX** ≥ 6.14.1
